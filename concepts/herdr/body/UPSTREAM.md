# Upstream-maintained body — not vendored here

The Herdr agent skill is maintained upstream at
[ogulcancelik/herdr](https://github.com/ogulcancelik/herdr) (`SKILL.md` at the repository root).
No copy is kept in this workspace by design: the upstream repository states no licence, so its
body is referenced rather than redistributed.

Install or refresh it through upstream's own channel, then expose it on the shared skill bus
alongside the concepts deployed from here. `CONCEPT.md` records the accuracy check, the pinned
commit, and the SHA-256 of the body that check was run against.

This mirrors the arrangement already used by `notebooklm` and `last30days`.
