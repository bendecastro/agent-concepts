# Security

## Reporting a vulnerability

Report security problems privately through GitHub: open the repository's
[Security tab](https://github.com/bendecastro/agent-concepts/security) and choose **Report a vulnerability**
([GitHub's guide](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)).
Please do not open a public issue for a security problem.

Examples of what to report here: a skill or the agent kernel that leads an agent to leak secrets,
run commands it was not asked to run, or follow instructions planted in files or web pages; an
install method that runs or installs something it should not.

Include the agent and version (`pi list`, or the plugin version), the skill, what happened, and
the steps or transcript excerpt that shows it, with secrets removed.

## Supported versions

Fixes go into the next release. Use the newest release; older releases do not get fixes.
