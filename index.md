### Workshop pipeline (Matt Pocock AI Engineer Workshop, ingested 2026-06-20)

The plan→execute lifecycle as composable skills. User-invoked orchestrators coordinate; model-invoked disciplines hold reusable behavior. The two `bc-` orchestrators wire the lifecycle into one **loop** — `bc-plan-to-issues` (interactive planning front) → `bc-drain-issues` (AFK execution, also deployed as `/implement`); see [pipeline.md](pipeline.md). The single-step orchestrators (`grill-me`, `to-spec`, `to-tickets`) remain for one-phase-at-a-time use; `/to-prd` and `/to-issues` are compatibility aliases.

- [grill-me](concepts/grill-me/CONCEPT.md) — user-invoked, **always-stateful** planning grilling: runs the `grilling` loop and persists resolved vocabulary + hard decisions into `CONTEXT.md`/ADRs via `domain-modeling` as it goes. Merge of Pocock's `grill-me` + `grill-with-docs` (user chose a single stateful skill).
  - Status: implemented 2026-06-20; pressure-tested + Claude Code symlink — see log.
- [grilling](concepts/grilling/CONCEPT.md) — model-invoked relentless one-question-at-a-time interview loop behind `grill-me`; recommended-answer-first, codebase-first, one-at-a-time gate with refuted excuses + a principled **bulk-delegation exit** (resolve all remaining branches with recommendations in one pass on blanket delegation).
  - Status: implemented 2026-06-20; bulk-exit clause added 2026-06-22 + pressure-tested **PASS** (bulk exit fires, 0 further questions, no premature build; soft note: under-used low-confidence flagging / "locked" wording); validated transitively via grill-me pressure test; Claude Code symlink.
- [domain-modeling](concepts/domain-modeling/CONCEPT.md) — model-invoked discipline: challenge vague terms into canonical names, stress-test with edge cases, keep `CONTEXT.md` a pure glossary, ADRs only at a three-part bar. The doc-writing engine behind stateful grill-me. Body adapted from an upstream summary (exact source text unrecovered).
  - Status: implemented 2026-06-20; accuracy check + transitive grill-me test; Claude Code symlink.
