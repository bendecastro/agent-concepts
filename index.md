### Workshop pipeline (Matt Pocock AI Engineer Workshop, ingested 2026-06-20)

The plan→execute lifecycle as composable skills. User-invoked orchestrators coordinate; model-invoked disciplines hold reusable behavior. The two `bc-` orchestrators wire the lifecycle into one **loop** — `bc-plan-to-issues` (interactive planning front) → `bc-drain-issues` (AFK execution, also deployed as `/implement`); see [pipeline.md](pipeline.md). The single-step orchestrators (`grill-me`, `to-spec`, `to-tickets`) remain for one-phase-at-a-time use; `/to-prd` and `/to-issues` are compatibility aliases.

- [grill-me](concepts/grill-me/CONCEPT.md) — user-invoked, **always-stateful** planning grilling: runs the `grilling` loop and persists resolved vocabulary + hard decisions into `CONTEXT.md`/ADRs via `domain-modeling` as it goes. Merge of Pocock's `grill-me` + `grill-with-docs` (user chose a single stateful skill). Status: implemented 2026-06-20; pressure-tested + Claude Code symlink — see log.
- [grilling](concepts/grilling/CONCEPT.md) — model-invoked relentless one-question-at-a-time interview loop behind `grill-me`; recommended-answer-first, codebase-first, one-at-a-time gate with refuted excuses + a principled **bulk-delegation exit** (resolve all remaining branches with recommendations in one pass on blanket delegation). Status: implemented 2026-06-20; bulk-exit clause added 2026-06-22 + pressure-tested **PASS** (bulk exit fires, 0 further questions, no premature build; soft note: under-used low-confidence flagging / "locked" wording); validated transitively via grill-me pressure test; Claude Code symlink.
- [domain-modeling](concepts/domain-modeling/CONCEPT.md) — model-invoked discipline: challenge vague terms into canonical names, stress-test with edge cases, keep `CONTEXT.md` a pure glossary, ADRs only at a three-part bar. The doc-writing engine behind stateful grill-me. Body adapted from an upstream summary (exact source text unrecovered). Status: implemented 2026-06-20; accuracy check + transitive grill-me test; Claude Code symlink.
- [to-spec](concepts/to-spec/CONCEPT.md) — user-invoked: run `prd-drafting` then publish the PRD-format spec as an unlabeled **GitHub** parent issue; `/to-prd` remains a compatibility alias and `ready-for-agent` is reserved for implementation slices. Status: renamed 2026-07-11; pressure-tested 2026-07-16 **PASS** (Grok unlabeled parent retest).
- [to-tickets](concepts/to-tickets/CONCEPT.md) — user-invoked: run `issue-slicing` then publish dependency-ordered GitHub tickets (issues); `/to-issues` remains a compatibility alias. Status: renamed 2026-07-11; pressure-tested 2026-07-16 **PASS** (Grok; quiz under attack + real #NN).
- [prd-drafting](concepts/prd-drafting/CONCEPT.md) — model-invoked: draft a PRD from the conversation + codebase (synthesize-not-interview, seam-first, standard template), no publishing. Extracted from `to-spec` so the loop orchestrator can inline it. Status: implemented 2026-06-20; accuracy check authored; **not yet deployed**.
- [issue-slicing](concepts/issue-slicing/CONCEPT.md) — model-invoked: break a plan/PRD into vertical tracer-bullet slices, fresh-context sized, with expand–contract for wide refactors, quiz-before-finalize, no publishing / no parent-touch. Extracted from `to-tickets` so the loop orchestrator can inline it. Status: updated 2026-07-11; pressure-tested 2026-07-16 **PASS** (Grok; trust/skip-review quiz gate held — prior FAIL cleared).
- [bc-plan-to-issues](concepts/bc-plan-to-issues/CONCEPT.md) — user-invoked loop front: one command running grill → domain capture → change folder (`docs/changes/<slug>/`: canonical `prd.md`, evidence, `tasks.md` manifest) → publish pointer-body parent → living-specs merge (`docs/specs/`, pending-tagged) → slice (publish `ready-for-agent`, dependency-ordered). Composes disciplines only; recommends `bc-drain-issues`. Status: implemented 2026-06-20; living-specs + change-folder 2026-07-12; pressure-tested 2026-07-16 **PASS** (Grok, 10/10 — prior 2026-06-21 FAIL cleared); deployed 2026-06-21.
- [bc-drain-issues](concepts/bc-drain-issues/CONCEPT.md) — user-invoked AFK executor (also `/implement` alias): preflight-gated driver loop, remote Git claim branch per issue, fresh worker plus blocking parallel Spec/Standards review before trunk-based commit/push/close, with park-and-continue + circuit-breaker + recurring-defect tune (driver patches the run-local worker packet when a failure shape recurs across workers; additive-only, canon untouched, patches quoted verbatim in the run report; separate-fixer role considered + rejected). Status: updated 2026-07-16 (recurring-defect tune); pressure-tested 2026-07-16 **PASS** (Grok, 13/13 incl. claim race + PRD closeout); deployed Claude Code + Pi.

Status: implemented 2026-07-11; pressure-tested 2026-07-16 **PASS** (Grok); deploy pending explicit request.
