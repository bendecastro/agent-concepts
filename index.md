### Workshop pipeline (Matt Pocock AI Engineer Workshop, ingested 2026-06-20)

The plan→execute lifecycle as composable skills. User-invoked orchestrators coordinate; model-invoked disciplines hold reusable behavior. The two `bc-` orchestrators wire the lifecycle into one **loop** — `bc-plan-to-issues` (interactive planning front) → `bc-drain-issues` (AFK execution); see [pipeline.md](pipeline.md). The single-step orchestrators (`grill-me`, `to-prd`, `to-issues`) remain for one-phase-at-a-time use.

- [grill-me](concepts/grill-me/CONCEPT.md) — user-invoked, **always-stateful** planning grilling: runs the `grilling` loop and persists resolved vocabulary + hard decisions into `CONTEXT.md`/ADRs via `domain-modeling` as it goes. Merge of Pocock's `grill-me` + `grill-with-docs` (user chose a single stateful skill). Status: implemented 2026-06-20; pressure-tested + Claude Code symlink — see log.
- [grilling](concepts/grilling/CONCEPT.md) — model-invoked relentless one-question-at-a-time interview loop behind `grill-me`; recommended-answer-first, codebase-first, one-at-a-time gate with refuted excuses + a principled **bulk-delegation exit** (resolve all remaining branches with recommendations in one pass on blanket delegation). Status: implemented 2026-06-20; bulk-exit clause added 2026-06-22 + pressure-tested **PASS** (bulk exit fires, 0 further questions, no premature build; soft note: under-used low-confidence flagging / "locked" wording); validated transitively via grill-me pressure test; Claude Code symlink.
- [domain-modeling](concepts/domain-modeling/CONCEPT.md) — model-invoked discipline: challenge vague terms into canonical names, stress-test with edge cases, keep `CONTEXT.md` a pure glossary, ADRs only at a three-part bar. The doc-writing engine behind stateful grill-me. Body adapted from an upstream summary (exact source text unrecovered). Status: implemented 2026-06-20; accuracy check + transitive grill-me test; Claude Code symlink.
- [to-prd](concepts/to-prd/CONCEPT.md) — user-invoked: run `prd-drafting` then publish the PRD as an unlabeled **GitHub** parent issue; `ready-for-agent` is reserved for implementation slices. Thin wrapper after the 2026-06-20 refactor (writing behavior lives in `prd-drafting`). Status: implemented 2026-06-20, rewired 2026-06-20, parent-label corrected 2026-06-26; pressure-tested 2026-06-21 **PASS** before label correction (rerun pending); Claude Code symlink.
- [to-issues](concepts/to-issues/CONCEPT.md) — user-invoked: run `issue-slicing` then publish slices as **GitHub** issues, dependency-ordered. Thin wrapper after the 2026-06-20 refactor (slicing behavior lives in `issue-slicing`). Status: implemented 2026-06-20, rewired 2026-06-20; pressure-tested 2026-06-21 **PASS** (delegated to vertical slicing, approval before publish, dep-ordered, no parent touch; minor: hardcoded `#NN` under stub); Claude Code symlink.
- [prd-drafting](concepts/prd-drafting/CONCEPT.md) — model-invoked: draft a PRD from the conversation + codebase (synthesize-not-interview, seam-first, standard template), no publishing. Extracted from `to-prd` so the loop orchestrator can inline it. Status: implemented 2026-06-20; accuracy check authored; **not yet deployed**.
- [issue-slicing](concepts/issue-slicing/CONCEPT.md) — model-invoked: break a plan/PRD into vertical tracer-bullet slices, quiz-before-finalize, no publishing / no parent-touch. Extracted from `to-issues` so the loop orchestrator can inline it. Status: implemented 2026-06-20; pressure-tested 2026-06-21 **FAIL** (waived the quiz/approval gate under "skip the review, I trust you") — SKILL fix + re-run needed; **not yet deployed**.
- [bc-plan-to-issues](concepts/bc-plan-to-issues/CONCEPT.md) — user-invoked loop front: one command running grill → domain capture → PRD (publish unlabeled parent) → slice (publish `ready-for-agent`, dependency-ordered). Composes disciplines only; recommends `bc-drain-issues`. Status: implemented 2026-06-20; updated 2026-06-26 so parent PRDs stay out of the drain queue and research/evidence stays distinct from actual PRDs; Pi pressure run 2026-06-21 **failed** (one-question gate/slicing approval/issue-reference placeholders); deployed 2026-06-21 by explicit user request despite failure, fix/re-test needed.
- [bc-drain-issues](concepts/bc-drain-issues/CONCEPT.md) — user-invoked AFK executor: preflight-gated (`publish-check.py`) driver loop, remote Git claim branch per issue for cross-runner parallel safety, fresh subagent per unblocked issue, trunk-based commit/push/close with park-and-continue + circuit-breaker. Two-file body (`SKILL.md` + `execute-issue.md`). Status: implemented 2026-06-20; Pi pressure run 2026-06-21 **passed before claim-branch addition** with stubbed `gh`/push; deployed to Claude Code + Pi symlinks 2026-06-21; concurrency pressure rerun pending.
- [bc-autoresearch-loop](concepts/bc-autoresearch-loop/CONCEPT.md) — model-invoked discipline: objective, bounded code improvement — name one metric, lock correctness, iterate one bounded change, keep only if tests still pass AND the metric provably improves (else revert); stops if no metric exists. Self-contained (idea from the Scripts `bc-improve` CLI, no dependency on it). Inlined conditionally by `bc-drain-issues` post-GREEN. Status: implemented 2026-06-21; Pi pressure run 2026-06-21 **passed**; deployed to Claude Code + Pi symlinks 2026-06-21.
- [bc-init-agent](concepts/bc-init-agent/CONCEPT.md) — user-invoked adaptive initializer: recon first, archetype choice, targeted grill, proposed init/migration plan, then deterministic repo-root `AGENTS.md` + `.bc-agent/` Markdown/Obsidian vault scaffold for the user's agent-maintained wiki pattern; supports code, ops, learning, knowledge, and hybrid wiki overlays; seeds minimal stable `.obsidian/` metadata; clobber-guarded; offers a publish.yaml rule, seeds `.bc-agent/out-of-scope/`, includes a loop skill map, and tells agents to offer `/bc-plan-to-issues` for planning-like codebase requests. The setup step before `triage` / `bc-plan-to-issues`. Status: implemented 2026-06-20; updated 2026-06-26 for planning-trigger + skill-map + research/PRD boundary, adaptive onboarding, wiki archetypes, minimal Obsidian vault metadata, and generalized wording; pressure-tested 2026-06-21 **PASS** for deterministic script + old process, new adaptive/archetype process scenarios pending; deployed to Claude Code + Pi symlinks.
- [triage](concepts/triage/CONCEPT.md) — user-invoked bc intake gate: verify issues/PRs, grill missing decisions, write drain-ready Agent Briefs, route broad work to `bc-plan-to-issues`, or record rejected enhancements in `.bc-agent/out-of-scope/`. Status: implemented 2026-06-21; pressure-tested 2026-06-21 **PASS** (needs-info/brief/out-of-scope routing, AI disclaimer, no code changes; fixture gap: no already-implemented case); deployed to Claude Code + Pi symlinks.

Status: implemented 2026-06-21; pressure-tested 2026-06-21 **PASS** (runnable terminal prototype, recorded verdict/run/disposition, no tests/abstractions); deployed to Claude Code + Pi symlinks.

Status: implemented 2026-06-21; pressure-tested 2026-06-21 **PASS** (read glossary/ADR, temp HTML report with deep-module vocab, asked which candidate, no prod edits/issues); deployed to Claude Code + Pi symlinks.
